% Acronyms of the document, declared as glossary entries:
% * "name"        -> The short form, the one shown in the text (e.g., "CNN")
% * "long"        -> The developed form shown in the list of acronyms, where the
%                    letters the short form is made of are usually put in bold
% * "description" -> What a reader sees when hovering the acronym in the document
% * "alt"         -> The key of the acronym this entry is a variation of (optional)

% In the document, use:
% * \acro{key}     -> Shows the short form, with the description as a tooltip (e.g., "CNN")
% * \acrofull{key} -> Shows the description, followed by the short form (e.g., "Convolutional Neural Network (CNN)")
% * \acroname{key} -> Shows the description only (e.g., "Convolutional Neural Network")

% The bold letters of a "long" field are normally typed by hand. Where they cannot
% be, \firstbold emboldens the first n letters of what it is given (n = 1 by
% default), be it text or another acronym:
% * \firstbold{Caltech}       -> "Caltech" with a bold C
% * \firstbold[3]{Biomedical} -> "Biomedical" with a bold Bio
% * \firstbold{\acro{key}}     -> the short form of another acronym, first letter in
%                                bold, keeping its tooltip and its link. Use it for
%                                a nested acronym that contributes only its first
%                                letters to the one being defined, as UCSD does in
%                                CUB: long = {\textbf{C}altech \firstbold{\acro{ucsd}} \textbf{B}irds}

% This file may hold more acronyms than a document uses: only the ones a document
% actually writes are listed in it, so the same file can serve several documents
% without each of them carrying the acronyms of the others. Writing an acronym in
% a bibliography entry counts as using it, and an acronym is turned into a link to
% that list only in the documents that do print it

% Variations -- a plural, an adjective, a translation -- are declared without a
% "long" field, and name in "alt" the key of the acronym they vary. Such an entry
% has no line of its own in the list: its link leads to the entry of that acronym,
% and writing only the variation is enough for that entry to be listed. Its own
% description is what its tooltip shows, so that a plural still reads as a plural

% An entry with neither "long" nor "alt" is never listed and never linked: it is
% reached through its tooltip only. Use it for an acronym you want to gloss on
% hover without giving it a line of its own

% This file is shared by the three example documents (HDR, HDR demand, PhD)
% Entries are sorted alphabetically, which is not required but makes edition easier

\newglossaryentry{ai}
{
    type        = {acronym},
    name        = {AI},
    long        = {\textbf{A}rtificial \textbf{I}ntelligence},
    description = {Artificial Intelligence}
}

% Example of a variation: the French counterpart of the acronym above
% It has no "long" of its own, so the list holds no line for it; "alt" sends both
% its link and the fact that it was used to the entry it varies
\newglossaryentry{ai_fr}
{
    type        = {acronym},
    name        = {IA},
    alt         = {ai},
    description = {Intelligence Artificielle}
}
